# Тестовое задание (Этап 1)

Дан статичный JSON-массив из 50 записей — список сотрудников (`data.json`, лежит рядом с этим
файлом): `id`, `fullName`, `department`, `hireDate`, `status`.

Реализовать React + TypeScript компонент таблицы:

1. Колонки с кликабельной сортировкой (цикл: asc → desc → без сортировки), активная
   отсортированная колонка визуально помечена.
2. Одно текстовое поле фильтра, фильтрующее по 2 указанным полям — имя (`fullName`) и отдел
   (`department`).
3. Чекбоксы выбора строк + чекбокс «выбрать все», счётчик «Выбрано: N».
4. Состояния: загрузка (эмулировать через `setTimeout`), пустой результат фильтра.
5. Строго по ТЗ — без лишних фич «от себя». Приложите README с инструкцией запуска.

Стек и инструментарий (Vite / CRA / CodeSandbox / что угодно на React+TS) — на ваш выбор,
это не оценивается.

**Как сдавать:** архив с проектом (без `node_modules`) или ссылка на приватный репозиторий /
CodeSandbox.
